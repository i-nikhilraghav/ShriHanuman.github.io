## 🌟 प्रमुख विशेषताएं (Key Highlights)

1. **५ पावन स्तोत्र व ऑडियो श्लोक पाठ**:
   - श्री हनुमान चालीसा (४३ श्लोक व दोहे)
   - श्री बजरंग बाण (१७ चौपाइयां व तांत्रिक मंत्र)
   - श्री संकटमोचन हनुमानाष्टक (९ पावन छंद व समापन दोहा)
   - श्री हनुमान बाहुक (६ असाध्य रोग नाशक पद)
   - श्री हनुमान जी की आरती (१३ पद व दोहा)
2. **श्री हनुमान के एकादश रुद्र स्वरूप (११ विशिष्ट चित्र)**:
   - पंचमुखी, एकादशमुखी, संकटमोचन द्रोणाचलधारी, वीर मारुति, भक्त, ध्यान, सूर्यशिष्य, लंकादहन, कपिध्वज, बाल मारुति, और प्रसन्नाञ्जनेय।
3. **डिजिटल जाप माला काउंटर**:
   - १०८ मनकों की चक्राकार विजुअल माला, मंत्र चयन, पूर्ण माला कन्फेटी एनीमेशन एवं घंटी ध्वनि।
4. **१०८ पावन नाम (अष्टोत्तर शतनामावली)**:
   - लाइव सर्च, संस्कृत नाम, हिंदी अर्थ व एक-क्लिक कॉपी।
5. **लाइव मंदिर दर्शन व वर्चुअल पूजा**:
   - सालासर, महंदीपुर, हनुमान गढ़ी, संकट मोचन वाराणसी, जाखू शिमला।
